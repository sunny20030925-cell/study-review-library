# 《產業經濟學》科目範圍

## 定位

- Book ID：`industrial-economics`
- 書名：《產業經濟學》
- 副標：市場結構・策略競爭・廠商行為與競爭政策
- 層級：一般大學產業經濟學／產業組織（Industrial Economics / Industrial Organization）共同核心，從個體經濟學基本直覺銜接一般大學課程與考試。
- 讀者起點：預設已接觸供需、成本、利潤最大化與基本微分，但正文會在需要時補上必要先備，不要求先修高階賽局理論或計量經濟學。

本書主線是「如何描述產業與市場力量 → 廠商如何定價與策略互動 → 市場結構如何由進入、差異化、垂直關係與創新形成 → 競爭政策如何評估市場結果」。與《個體經濟學》重疊的部分只保留產業組織分析不可缺的工具，不重做完整消費者理論或一般均衡；與《計量經濟學》重疊的實證內容只介紹產業分析所需的辨識與資料直覺，不發展完整估計理論。

## 核心範圍

1. 產業經濟學的問題、分析單位與 Structure–Conduct–Performance（SCP）框架及其限制。
2. 市場界定、市占率、集中度、CRn、HHI 與市場力量；集中度不等於競爭程度的單一充分指標。
3. 成本結構、規模經濟、範疇經濟、最低效率規模、沉沒成本與自然獨占的產業含義。
4. 單一產品獨占：MR=MC、加價、Lerner index、需求彈性、福利損失與價格上限的基本比較。
5. 價格歧視：一級、二級、三級、兩部定價、版本化；可行性取決於市場力量、分群／辨識與防套利等條件。
6. 寡占與賽局工具：最佳反應、Nash equilibrium、同時／序列決策、可信承諾與策略替代／互補的基本直覺。
7. Cournot 數量競爭：反應函數、對稱均衡、廠商數增加與競爭結果。
8. Bertrand 價格競爭：同質商品基準、Bertrand paradox，以及容量限制與差異化如何改變結果。
9. Stackelberg 領導者模型、先行者優勢與承諾；先行並非任何情境都必然有利。
10. 產品差異化與空間競爭：水平／垂直差異化、Hotelling 基本模型、定位與價格競爭。
11. 獨占性競爭與產品多樣性：固定成本、自由進入、超額產能與社會最適品種數的基本張力。
12. 進入、退出與進入障礙：結構性、策略性與制度性障礙；沉沒成本、極限定價與掠奪性定價的條件式分析。
13. 重複賽局、卡特爾與默契協調：折現因子、懲罰策略、偏離誘因與影響合謀穩定的市場條件。
14. 垂直關係與限制：雙重加價、轉售價格維持、獨家交易、搭售與垂直整合；同一安排可能同時有效率與排除效果。
15. 水平結合與併購：單邊效果、協調效果、效率抗辯、HHI 變動直覺與進入可能性；不把單一集中度門檻當成完整判決。
16. 廣告、資訊、搜尋成本與信號：資訊型／說服型廣告、價格分散、品質信號與消費者搜尋。
17. 研發、專利與創新競爭：創新誘因、Schumpeterian competition、專利保護、研發競賽與技術擴散。
18. 網路效果、相容性與平台市場：直接／間接網路效果、兩邊市場、跨邊外部性、多歸屬、臨界規模與平台定價。
19. 競爭政策與台灣制度銜接：相關市場、獨占、事業結合、聯合行為及其他限制競爭行為的經濟分析框架；法規內容以公平交易委員會最新公開資料為準。
20. 產業實證與案例分析入門：需求、成本、市場力量與進入的資料指標，結構式／簡化式研究問題的直覺，以及如何避免把相關性直接當因果。

## 深度邊界

正文與核心題庫不擴張至：

- 高階賽局理論的證明、連續時間動態賽局、機制設計、拍賣理論完整推導。
- 研究所等級的新實證產業組織（NEIO）估計、BLP 隨機係數需求、動態離散選擇、結構式反事實估計。
- 完整競爭法逐條釋義、行政程序、個案法律意見或申報實務。
- 產業政策、貿易政策、勞動經濟、公司治理、ESG、環境經濟或金融產業專論的大篇幅內容；除非為理解產業組織機制不可缺，否則只列延伸。
- 投資選股、產業投資建議、公司估值或即時市場預測。

上述內容若有助理解，只能以「延伸」或邊界說明出現，不占核心題庫與必讀進度。

## 重要精確性規則

- 一般金額例題使用新臺幣（NT$）。
- 市場集中度高不等於已證明市場力量高；市場界定、進入、產品差異、買方力量與競爭方式都會影響判斷。
- HHI 定義為各廠商市場占有率平方後加總；使用百分比數值時範圍為 0 至 10,000，使用比例時範圍為 0 至 1，兩種口徑不得混算。
- Lerner index `(P-MC)/P` 與需求彈性的簡單關係只在相應單一產品利潤最大化、可微需求等條件下使用，不當作所有市場力量的萬用估計式。
- Cournot、Bertrand、Stackelberg 的結論依決策變數、時序、產品同質性、容量與成本等假設而異，不把模型結論無條件外推。
- 價格歧視不必然降低福利；要看產量、分群、需求與固定成本等條件。
- 自由進入不保證社會最適廠商數或產品種類；商業攫取（business stealing）與產品多樣性利益需分開判斷。
- 卡特爾／協調必須區分「平行行為」與「存在合意或可持續協調機制」；經濟模型不等同法律上已成立聯合行為。
- 垂直限制與平台規則可能同時有促進效率與限制競爭效果，不以形式名稱直接判斷好壞。
- 台灣公平交易法的申報金額、主管機關處理原則與實務門檻可能更新；教材核心只固定長期概念，時效性制度資料以最新官方來源為準。

## 成品結構

- 正文：第 0 章至第 19 章，共 20 章。
- 附錄：核心公式與模型速查、產業經濟學解題路線、中英名詞對照，共 3 份。
- 題庫：100 題，每章 5 題，涵蓋基礎理解、標準計算／圖形判讀、模型比較、綜合判斷與常見陷阱。
- 搜尋索引：150 筆。
- 圖解：20 張自製 SVG，每章至少一張真正幫助理解的市場結構／策略互動／流程圖。
- 平板功能：沿用共同 PWA 的連續閱讀、章節導覽、全文搜尋、題庫練習、閱讀進度、錯題紀錄與離線快取。

## 參考口徑

- 一般大學 Industrial Organization / Industrial Economics 共同教材與公開課程，核心以市場力量、定價、寡占、進入、差異化、垂直關係、創新與競爭政策為主。
- MIT 14.20 Industrial Organization and Public Policy 與 MIT Industrial Organization 課程公開架構，用來交叉核對本科共同核心。
- 台灣公平交易委員會公開之相關市場、獨占、結合與聯合行為資料，用於競爭政策章的制度銜接。
- 即時產業數據、當期公司案例與易變門檻只作例示背景，不作需要背誦的固定教材內容。
