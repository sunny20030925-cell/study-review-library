## 2. 實質糾錯與補強

### 成本分類與材料流程

- 補入主要成本（直接材料＋直接人工）與加工成本（直接人工＋製造費用），並明確提醒兩者相加會重複計入直接人工。
- 材料耗用公式中的「進料」改明定為淨進料；若題目另給進貨運費、退回或折讓，須先調整。

### CVP 與分步成本制

- CVP 假設補上固定銷售組合，並明確區分貢獻邊際式分析與吸收成本法下存貨變動造成的固定製造費用遞延／釋放。
- 加權平均法改為材料、加工等各成本成分分別計算約當產量與每約當單位成本，不再以單一分母混算。
- FIFO 轉入成本補分清期初在製品所帶前期成本與本期轉入成本；轉入成本完工程度不得直接套用本部門加工完工程度。

### 損壞品、聯產品與副產品

- 正常損壞改以檢驗點為判斷核心；尚未到達檢驗點的期末在製品，通常不吸收該檢驗點才辨認的正常損壞成本。
- 聯合成本補入物量法及其限制。
- 原章名雖含副產品但正文不足，本輪補入副產品的相對不重大特徵、淨變現價值沖減成本與出售時列收入等常見處理。

### 標準成本差異

- 材料價格差異不再用含糊的 `AQ` 同時代表購買量與使用量。
- 購買時認列價格差異使用實際購買量 `AQP`；使用時認列才使用實際使用量 `AQU`。
- 材料用量差異固定比較 `AQU` 與實際產出允許的標準用量 `SQ`。
- 例題與 `ch14-q01` 同步由 NT$5,200 U 修正為 NT$5,400 U。

### 吸收成本法與產能

- 吸收成本法改為「合理分攤」的固定製造費用進入產品成本，並補入正常產能原則。
- 異常低產量所形成的未分攤固定製造費用，明定為當期費用，不得藉由縮小實際分母全部資本化進存貨。
- 異常高產量時應降低單位分攤率，避免分攤超過實際發生固定製造費用。
- 吸收與變動成本法利益調節改用「期末存貨內含固定 OH－期初存貨內含固定 OH」的一般式；只有固定率相同且無其他差異時，才簡化為存貨增加單位乘每單位固定 OH。
- 重新區分理論產能、實務產能、正常產能與預算產能。
