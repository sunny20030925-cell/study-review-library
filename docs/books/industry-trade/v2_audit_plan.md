# 《產業及貿易》發布後二次內容審計

更新日期：2026-07-30

## 目的

針對正式 v1 教材做發布後獨立內容複核，不只重跑原候選 QA。檢查正文、公式成立條件、例題、100 題題庫、搜尋索引與高風險定義，發現問題即修正；章節 ID、題目 ID、題數與平板進度儲存相容性必須保持。

## 本次確認需修正的內容

1. 需求彈性定義補齊百分比比率與符號慣例。
2. CES 固定彈性壟斷性競爭補明固定加成邊界。
3. 策略性出口補貼福利帳補明利潤是否包含補貼收入，避免雙重計帳。
4. FDI 由過強的「取得並控制」改為 lasting interest 與 significant influence/control，並補直接投資統計的 10% 投票權基準；FDI／出口臨界式改用相對固定成本與相對單位成本節省。
5. Nash 議價納入 disagreement payoffs；雙邊壟斷定義改為一個買方與一個賣方。
6. FTA／關稅同盟定義與貿易轉向福利帳精確化，避免關稅收入與真實資源成本重複扣除。
7. 全 20 章的「常見錯誤」題詳解重寫，使答案直接糾正題幹中的錯誤，並清除重複句號生成瑕疵。
8. 反傾銷章重新核對 normal value／export price、公平比較、material injury 與 causal link；核心架構目前無需改寫。
