# 《計算機概論》科目範圍

## 定位

- Book ID：`computer-fundamentals`
- 書名：《計算機概論》
- 副標：資料表示・硬體・作業系統・網路・演算法與資訊科技
- 層級：一般大學「計算機概論／Introduction to Computer Science / Computing Fundamentals」共同核心，從接近零基礎銜接一般大學課程與考試。
- 讀者起點：不要求先修程式設計、離散數學、計算機結構或網路；需要的二進位、邏輯與簡單演算法概念在正文內補足。

本書以「資訊如何被表示 → 計算機如何執行 → 作業系統如何管理資源 → 網路如何交換資料 → 程式與演算法如何解題 → 資料如何組織 → 現代資訊系統如何兼顧安全、AI 與社會責任」為主線。程式設計只教理解計算機科學所需的共通概念與偽程式，不把本書改寫成特定語言的程式設計課；硬體、作業系統、資料庫、網路與 AI 也只到計算機概論合理深度。

## 核心範圍

1. 計算機與資訊系統全貌：硬體、軟體、資料、使用者、程序與網路；輸入—處理—輸出—儲存循環。
2. 數字系統：二進位、十進位、十六進位、位元與位元組、進位轉換與容量單位。
3. 資料表示：無號整數、二補數、有號整數範圍、浮點數近似、文字編碼、影像與聲音的數位化。
4. 數位邏輯：Boolean 值、AND／OR／NOT／XOR、真值表、邏輯閘與組合邏輯的直覺。
5. 計算機組織：CPU、ALU、控制單元、暫存器、匯流排、指令週期與機器指令的基本概念。
6. 記憶體與儲存階層：暫存器、快取、RAM、SSD／HDD；延遲、容量、成本、揮發性與區域性。
7. 輸入輸出與週邊：裝置控制、驅動程式、中斷、緩衝、常見輸入輸出設備與介面。
8. 作業系統（一）：核心、系統呼叫、程序、執行緒、排程、並行與平行的基本區別。
9. 作業系統（二）：虛擬記憶體、分頁、檔案系統、權限、虛擬機與容器的入門直覺。
10. 網路基礎：分層、封包、頻寬、延遲、交換、路由、MAC 與 IP 的角色。
11. Internet 與 Web：IPv4／IPv6、DNS、TCP／UDP、HTTP／HTTPS、URL、瀏覽器—伺服器模型與基本網路應用。
12. 程式語言與程式執行：變數、型別、運算、條件、迴圈、函式、編譯器、直譯器與執行環境。
13. 演算法與複雜度：演算法特性、偽程式、搜尋、排序、正確性直覺、時間／空間複雜度與 Big-O。
14. 資料結構：陣列、串列、堆疊、佇列、樹、雜湊表與圖的用途、操作與基本成本。
15. 資料庫：資料模型、關聯表、主鍵／外鍵、SQL 基本操作、正規化直覺、交易與 ACID 概念。
16. 軟體工程：需求、設計、實作、測試、除錯、版本控制、模組化、API 與軟體生命週期。
17. 資訊安全：CIA、認證與授權、密碼雜湊、對稱／非對稱加密、TLS、惡意程式、社交工程、備份與最小權限。
18. 人工智慧與資料：AI／ML 的基本關係、訓練與推論、監督式學習直覺、模型評估、生成式 AI 的能力與限制。
19. 現代運算平台：雲端運算、虛擬化、分散式系統、邊緣運算、IoT 與可擴充性／可用性的基本權衡。
20. 資訊社會、倫理與整合：隱私、個資、著作權、開源授權、數位落差、可近用性、偏誤與負責任使用科技；全書系統觀整合。

## 深度邊界

正文與核心題庫不擴張至：

- 特定程式語言的完整語法、物件導向設計模式、競賽程式或大型專案實作。
- 數位邏輯電路化簡、Karnaugh map、HDL、微架構、管線 hazard、快取一致性等專門計算機組織深度。
- 作業系統核心實作、同步原語證明、頁面置換演算法的進階分析或檔案系統內部資料結構。
- 網路協定 RFC 細節、子網設計大量計算、路由協定實作、無線通訊實體層工程。
- 資料結構與演算法的嚴格證明、NP-completeness、進階圖論與攤銷分析。
- 資料庫查詢最佳化、分散式交易、進階索引結構與 DBA 實務。
- 滲透測試、漏洞利用、惡意程式製作或攻擊步驟；資安內容維持防禦與原理本位。
- 機器學習高階數學、深度學習架構推導、模型訓練工程與特定生成式 AI 產品操作手冊。

上述內容若有助於理解，只能以「延伸」或邊界說明出現，不占核心題庫與必讀進度。

## 重要精確性規則

- `bit` 與 `byte` 必須分清楚；1 byte = 8 bits。網路速率常用 bit/s，檔案容量常用 byte。
- 十進位 SI 前綴與二進位 IEC 前綴分開：1 kB = 1000 B；1 KiB = 1024 B。若題目沿用傳統「KB=1024 B」，必須明示題目採用的約定。
- n 位元無號整數範圍為 0 到 2^n−1；n 位元二補數有號整數範圍為 −2^(n−1) 到 2^(n−1)−1。
- 浮點數是有限位元的近似表示；不得寫成「電腦能精確表示所有實數」。
- CPU 時脈較高不等於任何工作一定較快；效能仍受 IPC、核心數、記憶體、快取、I/O、軟體與工作負載影響。
- 快取、RAM、SSD／HDD 是不同層級；虛擬記憶體不是「把硬碟當成更慢的 RAM」這一句就能完整描述，而是位址空間與映射機制，換頁／交換只是其可能部分。
- 程序（process）與執行緒（thread）分開；並行（concurrency）不必然同時執行，平行（parallelism）才強調同時在多個執行資源上進行。
- TCP 提供可靠、有序的位元組串流；UDP 提供較精簡的資料報服務。不得寫成「TCP 一定慢、UDP 一定快」。
- HTTP 是應用層協定；HTTPS 是 HTTP 在 TLS 保護下傳輸，不等於「網站內容一定可信」。DNS 負責名稱解析，不是搜尋引擎。
- Big-O 描述漸近成長上界／等級，不能直接等同實際秒數；不同演算法在小輸入、硬體與常數因子下仍可能有不同表現。
- 雜湊（hashing）與加密（encryption）不是同一件事；密碼儲存應使用適合密碼的慢速雜湊／KDF 與 salt，而不是可逆加密或一般快速雜湊。
- AI 模型輸出是推論結果，不保證真實、完整或無偏；生成式 AI 的內容必須可被外部事實與來源驗證。
- 快速變動的硬體型號、軟體版本、市占率、AI 產品名稱與網路服務價格不寫成需背誦的核心知識。

## 成品結構

- 正文：第 0 章至第 19 章，共 20 章。
- 附錄：數字／資料表示與單位速查、計算機概論解題路線、中英名詞對照，共 3 份。
- 題庫：100 題，每章 5 題，涵蓋基礎理解、標準轉換／計算、結構判讀、綜合判斷與常見陷阱。
- 搜尋索引：150 筆。
- 圖解：20 張自製 SVG，每章至少一張真正幫助理解的結構圖、流程圖或分層圖。
- 平板功能：沿用共同 PWA 的連續閱讀、章節導覽、全文搜尋、題庫練習、閱讀進度、錯題紀錄與離線快取。
