## 已固定內容

- 科目定位與先備知識。
- 25 個正文章節的核心範圍。
- 3 個附錄的預定結構。

1. 建立章節資料結構、manifest、搜尋與題庫骨架。
2. 完成第 0 至第 24 章正文、例題與圖解。
3. 完成 3 個附錄與 125 題題庫。
4. 執行第一輪內容與結構檢查。
5. 執行第二輪獨立重算、準則邏輯複核與成品驗證。
6. 整合 canonical `Deploy study library`，確認既有六本書進度與錯題紀錄不受影響。
7. 正式部署並更新 shared checkpoint 與部署回條。

## QA 門檻

### 第一輪：內容與結構

- 章節範圍與先備知識連續。
- 認列、衡量、表達與揭露用語一致。
- 分錄借貸平衡，計算表與報表影響可相互勾稽。
- 利息、現值、折舊、減損、所得稅、租賃與每股盈餘公式附條件與期間基礎。
- 每章固定 5 題；章節 ID 與題目 ID 獨立於其他書籍。
- SVG、搜尋索引、manifest 與離線資產結構完整。

### 第二輪：獨立複核

- 每個核心處理重新核對適用條件與方向。
- 每道例題與每個數值答案由原始資料重新計算。
- 每道分錄重新檢查借貸、金額、日期與財報分類。
- 檢查前後章節矛盾、流動／非流動分類、損益／其他綜合損益／權益混用。
- 對準則版本敏感內容進行正式來源交叉核對。
- 平板直式閱讀、搜尋、題庫、翻頁與離線快取全部通過後才可發布。

## 相容性要求

- 新增獨立 Book ID，不變更既有書籍章節或題目 ID。
- 不重設既有閱讀進度與錯題紀錄。
- 沿用同一套平板 PWA 閱讀、搜尋、題庫與離線機制。
- 不建立會覆蓋現有書庫的平行 Pages 部署流程。
