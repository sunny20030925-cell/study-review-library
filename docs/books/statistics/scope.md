# 《統計學》科目範圍

更新日期：2026-07-29

## 教材定位

本書定位為一般大學第一門統計學的簡易教科書，適合從接近零基礎開始，逐步銜接大學課程、期中期末考與基礎應用題。

教材以統計推理本身為主，不依特定科系改寫成經濟統計、商業統計、心理統計或工程統計。例子可取自生活、教育、醫療、商業與社會資料，但只用來幫助理解，不主導章節結構與核心題型。

## 核心學習目標

完成本書後，讀者應能：

1. 分辨母體、樣本、參數、統計量與變數尺度。
2. 整理資料並正確解讀表格、圖形與描述統計量。
3. 理解機率規則、條件機率、獨立性與貝氏定理的基本用法。
4. 使用常見離散與連續機率分配解題。
5. 理解抽樣分配、中央極限定理、標準誤與估計誤差。
6. 建立與解讀平均數、比例、平均數差與比例差的信賴區間。
7. 正確執行與解讀常見假設檢定，區分統計顯著與實質重要。
8. 理解第一類錯誤、第二類錯誤、檢定力、效果量與樣本數之間的關係。
9. 分析類別資料、變異數分析、相關與簡單線性迴歸。
10. 辨認常見統計誤用，包括因果混淆、選樣偏誤、多重比較與只看 p 值。

## 明確排除

正文與核心題庫不擴張至：

- 數理統計的完整證明體系，包括機率測度、矩母函數推導、充分統計量、完備性、最大概似的大樣本理論與 Neyman–Pearson 理論。
- 多變量統計、時間序列、貝氏統計、抽樣調查理論、存活分析、品質管制與實驗設計的完整專門課程。
- 計量經濟學、商業分析、心理計量、生物統計或工程統計的專屬模型與軟體流程。
- 多元線性迴歸、邏輯斯迴歸、廣義線性模型與機器學習的完整建模課程。
- 以任何特定統計軟體、程式語言或試算表操作取代統計概念與手算基礎。
- 大量查表技巧、冷僻分配或只為背誦公式而存在的題型。

上述主題若有助於理解後續方向，只能放在「選讀／延伸」或課程地圖中，不占用核心閱讀進度。

## 深度控制

- 先說明研究問題與直覺，再介紹符號、公式、條件與計算。
- 每個推論方法都必須明示：資料型態、樣本關係、母體數量、必要假設、檢定統計量、自由度、p 值與結論語句。
- 不把「p 值小」寫成虛無假設為假的機率，也不把未拒絕虛無假設寫成證明虛無假設成立。
- 不以常態分配涵蓋所有情況；清楚說明小樣本、偏態、離群值與類別資料限制。
- 公式計算與結果解讀同等重要，核心題庫必須同時包含手算、方法選擇、圖表判讀與文字結論。
- 表格與圖形應使用自製 SVG 或 HTML 結構，能在平板放大閱讀。
