# 《統計學》科目範圍

## 定位

- Book ID：`statistics`
- 書名：《統計學》
- 副標：從資料描述到推論・大學入門統計
- 層級：一般大學第一門統計學／基礎統計學。
- 讀者起點：可從接近零基礎開始，不預設已修過統計學。

本書採標準大學入門統計學定位。前半部建立資料、描述統計、機率與常見機率分配；後半部建立抽樣分配、估計、假設檢定、兩群比較、類別資料、ANOVA、相關與簡單線性迴歸。

## 核心範圍

1. 母體、樣本、參數、統計量、變數與資料尺度。
2. 資料蒐集、抽樣方法、觀察研究、實驗設計、偏誤與混淆。
3. 次數分配、直方圖、長條圖、盒鬚圖、散布圖與分布形狀。
4. 平均數、中位數、眾數、百分位數、四分位數與位置量數。
5. 全距、四分位距、變異數、標準差、變異係數與標準分數。
6. 樣本空間、事件、加法與乘法規則、排列與組合。
7. 條件機率、獨立事件、全機率概念與貝氏定理。
8. 離散隨機變數、機率分配、期望值與變異數。
9. 二項分配、卜瓦松分配與常見計數模型。
10. 連續隨機變數、機率密度、常態分配與常態機率計算。
11. 抽樣分配、標準誤、大數法則直覺與中央極限定理。
12. 點估計、估計量概念、信賴區間、誤差界限與樣本數概念。
13. 假設檢定、虛無與對立假設、顯著水準、p 值、第一與第二類錯誤及檢定力直覺。
14. 單一母體平均數與比例的常見區間估計與檢定。
15. 兩獨立母體比較、成對資料與差異的推論。
16. 卡方適合度檢定、獨立性檢定與類別資料分析。
17. 單因子變異數分析、組間與組內變異及 F 檢定。
18. Pearson 相關、簡單線性迴歸、殘差、決定係數與斜率推論基礎。
19. 基礎非參數方法、統計結果報告、相關不等於因果及常見誤用。

## 明確排除

正文與核心題庫不擴張至：

- 測度論機率、嚴格機率空間與高等機率論證明。
- 數理統計中大量以微積分、矩陣或漸近理論為核心的推導。
- 最大概似估計的高階理論、充分性、完備性、指數族與一致最強力檢定等專門主題。
- 多元迴歸的矩陣推導、廣義線性模型、多變量分析、時間序列、生存分析與高等貝氏統計。
- 計量經濟學的因果識別、工具變數、固定效果、差異中的差異等專門內容。
- 綁定特定統計軟體、程式語言或套件操作的實作課程。
- 需要查閱即時資料才能成立的政策或產業分析。

上述項目只保留在範圍治理文件，不在學習正文反覆提示。

## 深度控制

- 先用正常中文建立直覺，再給正式定義、符號、公式、圖形、成立條件與標準例題。
- 公式以一般大學入門統計課程常用程度為限；不為追求完整而加入不必要的高等數學證明。
- 推論題必須說明使用條件、參數目標與結論能說到哪裡，避免只背公式。
- 圖表與資料例子以理解統計概念為主，不把其他學科案例變成教材主線。
- 常見臨界值與近似方法會標示適用條件；不同教材慣例有差異時，以入門課程最常見做法為主。
