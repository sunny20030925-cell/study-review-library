## 本輪實際內容修正

正文與附錄共有 19 個實質內容修正點，另有 3 題題庫同步精確化。

1. **隨機分派**：把「長期上平衡混雜因子」改成更精確的隨機化解讀；各組是在重複隨機化意義下平均可比，單一實驗仍可能偶然不平衡。
2. **不等組距直方圖**：不再把等組距寫成絕對規則；若組距不同，柱高須改用次數密度或相對次數密度，使柱面積對應次數或比例。
3. **變異係數 CV**：限縮到同類、具有真實零點的比率尺度資料；同一變數做正比例單位換算時 CV 不變，但不能因 CV 無單位就任意比較性質不同的變數。
4. **柴比雪夫不等式**：補上常用形式的 `k > 1` 條件。
5. **乘法規則**：明定一般情況使用條件機率；只有獨立事件才可簡化為邊際機率直接相乘。
6. **兩隨機變數的變異數**：補正一般公式為 `Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)`，並說明獨立可推出協方差為 0，但反向不成立於一般情況。
7. **連續均勻分配**：補上區間機率公式的 `a ≤ c ≤ d ≤ b` 範圍條件。
8. **平均數 z 信賴區間**：補上觀察值獨立及母體近似常態／樣本量足以常態近似的條件，並明定母體標準差已知才使用該 z 形式。
9. **t 信賴區間**：補上觀察值獨立；小樣本時特別檢查母體近似常態與嚴重離群值。
10. **單一比例信賴區間**：補上基本常態近似的成功／失敗數條件，並提醒小樣本或極端比例可考慮 Wilson 或精確區間。
11. **p 值**：把「目前或更極端」改成依對立假設方向所定義的「同等或更極端」，避免單尾、雙尾解讀含糊。
12. **單一比例 z 檢定**：明定虛無標準誤與常態近似條件在 `H0` 下用 `p0` 檢查，而信賴區間基本標準誤使用樣本比例 `p-hat`。
13. **兩母體比例**：正文新增未合併的信賴區間標準誤 `SE_CI`，以及 `H0:p1=p2` 下以合併比例計算的虛無標準誤 `SE_0`，不再只寫「區間不合併、檢定合併」而省略公式。
14. **非參數方法**：補上 Wilcoxon 符號等級檢定常見位置解讀的近似對稱條件；Mann–Whitney 本質上比較秩分布，只有形狀相近、主要差在位置時才可直接作中位數／位置差解讀。
15. **公式速查附錄**：補入協方差項公式，並區分比例區間以 `p-hat` 估計標準誤與比例檢定使用 `p0` 的用途。
16. **解題路線附錄**：將「一個平均數用 t 或 z」改為「母體標準差未知時通常用 t；母體標準差已知等特定條件才用 z」。
17. **題庫 ch01-q03**：同步修正隨機分派的答案與詳解，避免暗示單次實驗必然平衡。
18. **題庫 ch04-q05**：同步修正 CV 的適用尺度與比較範圍。
19. **題庫 ch17-q02**：題幹明定「含截距的簡單線性迴歸」，再使用 `R²=r²`；答案仍為 0.64，數值不變。
