# 《財政學》科目範圍

## 定位

- Book ID：`public-finance`
- 書名：《財政學》
- 副標：公共支出・租稅・分配・地方財政
- 層級：一般大學財政學／公共經濟學核心課程；深度高於《經濟學原理》的政府與市場失靈單元，但不進入研究所公共經濟理論或專門財稅法規課程。
- 讀者起點：可從接近零基礎開始；正文會補足必要的供需、彈性、剩餘、現值與福利分析，不要求先完整修過中級個體經濟學。

本書以一般大學一學期財政學（Public Finance / Public Economics）的共同核心為主。主線分成四塊：政府介入與公共支出、分配與社會保險、租稅理論與主要稅目、地方財政與政府債務。

## 核心範圍

1. 財政學的分析地圖：政府部門、實證分析與規範分析、效率與公平、政府收入與支出的基本分類。
2. 福利經濟學基礎：Pareto 效率、社會剩餘、福利經濟學基本定理、效率與公平的區分、社會福利函數。
3. 市場失靈與政府工具：公共財、外部性、不完全資訊、市場力，以及稅、補貼、規制、公共提供等工具的比較。
4. 公共財：非敵對性、非排他性、搭便車、Samuelson 條件、公共提供與 Lindahl 價格的直覺。
5. 外部性與環境政策：邊際外部成本／利益、Pigouvian 稅補貼、Coase 定理的成立條件、數量管制與可交易許可。
6. 公共選擇：多數決、單峰偏好、中位數選民定理、投票悖論、換票、尋租與政府失靈。
7. 成本效益分析：社會成本與效益、折現、淨現值、影子價格、機會成本、風險與分配效果。
8. 所得分配與貧窮：Lorenz curve、Gini coefficient、貧窮線、水平／垂直公平、現金與實物移轉、負所得稅直覺。
9. 社會保險與退休制度：保險原理、逆選擇、道德風險、失業保險、隨收隨付與完全提存退休制度、代際負擔。
10. 醫療與健康政策：醫療保險市場失靈、共付、供給者誘因、資訊不對稱、公共保險與效率公平取捨。
11. 教育與公共支出：人力資本、教育外部性、信號效果、公共提供、補貼、學貸與教育選擇的政策取捨。
12. 租稅原則與稅制設計：受益原則、量能原則、水平／垂直公平、平均與邊際稅率、比例／累進／累退、稅基與稅式支出。
13. 租稅歸宿：法定歸宿與經濟歸宿、供需彈性、從量稅與從價稅、短期與長期、部分均衡與一般均衡直覺。
14. 租稅超額負擔：稅楔、無謂損失、補償變量直覺、彈性與稅率對超額負擔的影響、既有扭曲與次佳理論的邊界。
15. 最適課稅：效率與公平的取捨、Ramsey inverse-elasticity rule 的簡化直覺、最適商品稅、最適所得稅的核心概念。
16. 個人所得課稅：綜合／分類所得概念、扣除與抵免、勞動供給、儲蓄誘因、負所得稅／工作補貼的基本設計。
17. 公司所得課稅：經濟利潤與正常報酬、利息與股利融資差異、折舊與投資誘因、公司稅歸宿的開放經濟直覺。
18. 消費、財產與財富課稅：一般銷售稅、加值型營業稅、貨物稅、財產稅、土地與財富課稅的稅基、歸宿與效率公平問題。
19. 地方財政與財政聯邦主義：中央與地方分工、Tiebout 模型、地方公共財、租稅競爭、垂直／水平財政不平衡、政府間移轉。
20. 政府預算、赤字與公債：年度赤字與債務存量、政府跨期預算限制、利率與成長率、債務動態、代際負擔與財政永續。

## 深度邊界

正文與核心題庫不擴張至：

- Mirrlees 最適所得稅模型的正式機制設計、顯示原理或高階最適控制推導。
- 一般均衡租稅歸宿模型的矩陣推導、Diamond–Mirrlees 生產效率定理的正式證明。
- 高階政治經濟模型、機制設計、拍賣理論或社會選擇理論的證明型內容。
- 各年度臺灣稅率、扣除額、申報門檻與特定稅法條文的背誦；這些會隨年度修法變動，不作核心教材依據。
- 租稅法、預算法、財政收支劃分法等法律課程的逐條法規解析。
- 完整總體財政政策模型、IS–LM／AD–AS、DSGE 或景氣穩定政策；這些屬《總體經濟學》的主體。
- 個別政黨或單一政策的政治立場、投資建議或價值宣傳。

上述內容如需提到，只能作為「延伸」用來說明模型邊界，不納入核心考試進度。

## 文字、公式與例題規則

- 先用正常中文建立直覺，再給正式定義、圖形、公式與成立條件。
- 一般金額例題一律使用新臺幣 `NT$`；涉及百分比或稅率時，清楚區分「百分比」與「百分點」。
- 福利分析必須區分效率判斷與公平判斷；不能把「總剩餘增加」直接寫成「所有人都更好」。
- 租稅歸宿一律區分法定納稅人與最終經濟負擔者，並寫出需求／供給彈性的條件。
- 公債章若使用 `Δb ≈ (r-g)b-d` 類型的債務動態式，必須先定義債務比、實質利率、實質成長率與初級赤字／盈餘的正負號。
- 臺灣制度只作不依賴當年度稅率的背景例子；任何會隨年度修法變動的數字不進入核心題庫。
