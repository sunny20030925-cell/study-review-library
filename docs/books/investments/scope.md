# 《投資學》科目範圍

## 定位

- Book ID：`investments`
- 書名：《投資學》
- 副標：報酬與風險・投資組合・資產定價・證券分析
- 層級：一般大學投資學／Investments，共同核心從接近零基礎銜接一般大學課程與考試。
- 讀者起點：不要求先完整修過財務管理或貨幣銀行學；正文補足時間價值、機率統計、證券市場與必要財報閱讀直覺。

本書以「投資環境與報酬衡量 → 風險與投資組合 → 資產定價 → 市場效率與行為 → 股票與債券估值 → 衍生工具 → 基金、資產配置與績效評估」為主線。它是學術型投資教材，不提供個別證券推薦、即時交易訊號或保證獲利策略。

## 核心範圍

1. 投資學的分析地圖：投資決策、資產類別、風險、報酬、價格與投資組合。
2. 金融市場與交易機制：初級／次級市場、交易所／店頭市場、委託類型、保證金與放空的基本機制。
3. 持有期間報酬、算術／幾何平均、複利、名目／實質報酬與風險溢酬。
4. 報酬分配、期望值、變異數、標準差、共變異數、相關係數與下行風險直覺。
5. 風險厭惡、效用、無風險資產與資本配置線（CAL）。
6. 分散化、兩資產與多資產投資組合、投資組合期望報酬與變異數。
7. Markowitz 平均數—變異數模型、可行集合、效率前緣、最低變異投資組合與限制條件。
8. 單一指數模型、系統性／非系統性風險與 beta。
9. CAPM、證券市場線（SML）、市場風險溢酬與 alpha 的正確解讀。
10. APT 與多因子模型：因子曝險、因子風險溢酬、分散化與套利直覺。
11. 效率市場假說、資訊集合、事件研究、主動／被動管理與異常現象的證據解讀。
12. 行為財務：有限理性、過度自信、損失趨避、框架、代表性、心理帳戶與套利限制。
13. 股票估值：股利折現模型（DDM）、固定成長模型、多階段成長與相對估值倍數。
14. 基本面分析：財務報表、ROE、盈餘品質、成長、估值驅動因子與產業／公司分析。
15. 債券定價、票息、面額、到期殖利率、即期利率與債券報酬來源。
16. 利率風險：Macaulay／修正存續期間、凸性、免疫策略與再平衡。
17. 債券信用風險、信用利差、評等、違約損失與期限結構的投資解讀。
18. 遠期與期貨：多空損益、基差、避險比率與現貨—期貨關係的基本條件。
19. 選擇權：call／put 損益、內含價值、put–call parity、二項式風險中立定價與 Black–Scholes 直覺。
20. 基金、ETF、指數化與投資成本；分清淨值、交易價格、追蹤誤差與槓桿／反向產品的路徑風險。
21. 資產配置、投資政策、再平衡與國際分散化；時間視野、風險承受度與匯率風險。
22. 投資績效衡量與主動管理：Sharpe、Treynor、Jensen alpha、資訊比率、追蹤誤差與績效歸因。

## 深度邊界

正文與核心題庫不擴張至：

- 高階連續時間資產定價、隨機微積分、完整 Black–Scholes PDE 推導或高階希臘字母避險。
- 高頻交易、演算法交易、程式化下單、技術指標參數最佳化或個別市場短線策略。
- 公司理財的完整資本預算、資本結構、股利政策與併購專題。
- 會計準則逐條處理；財報只保留投資分析所需的判讀。
- 金融機構監理、中央銀行操作與貨幣政策的完整體系；該部分留在《貨幣銀行學》。
- 個別股票、ETF、債券、期貨或選擇權的即時買賣建議、目標價與報酬保證。

上述內容若有助於理解，只能放在「延伸」或短邊界說明，不占核心題庫與必讀進度。

## 重要精確性規則

- 一般金額例題使用新臺幣（NT$）。涉及海外資產或匯率時，題目會明確指定報價方式。
- 報酬率先分單期／多期、算術／幾何平均；多期累積不得直接把百分比相加。
- 實質報酬精確式為 `(1+R_real)=(1+R_nominal)/(1+π)`；低通膨時才可用 `R_real≈R_nominal-π`。
- 投資組合風險必須保留共變異數項；「持有很多證券」不等於必然充分分散。
- CAPM 是條件式模型。beta 衡量相對市場的系統性風險，不代表總風險，也不保證未來報酬。
- Jensen alpha、歷史超額報酬或回測結果都不等於未來可持續的超額獲利。
- 效率市場假說不等於「價格永遠正確」，也不等於「任何主動管理者都不可能在任何期間勝過市場」。
- Gordon 固定成長 DDM `P0=D1/(k-g)` 必須有長期穩定成長且 `k>g`；不得把短期高成長率永久外推。
- YTM 是使債券未來現金流折現後等於市價的單一內部報酬率口徑；把 YTM 當成持有到期必然實現報酬時，要明示再投資與無違約等條件。
- 修正存續期間的價格近似只適合殖利率小幅變動；非平行利率曲線變動與大型變動需要更完整分析。
- Put–call parity 必須明示歐式選擇權、相同標的／履約價／到期日，以及股利等調整條件。
- Black–Scholes 只作標準模型直覺與基本應用，不把其假設當成現實市場事實。
- 分散化能降低可分散風險，但不能保證市場下跌時不虧損。
- 交易制度、稅率、費率、漲跌幅與商品規則可能調整；核心教材不把易變數值寫成永久定義，若舉例必須標示日期與官方來源。

- 正文：第 0 章至第 21 章，共 22 章。

- 圖解：22 張自製 SVG，每章至少一張真正幫助理解的結構圖、曲線圖、現金流圖或損益圖。
- 平板功能：沿用共同 PWA 的連續閱讀、章節導覽、全文搜尋、題庫練習、閱讀進度、錯題紀錄與離線快取。

## 參考口徑

- 以一般大學 Investments 課程共同核心為主，包括投資組合理論、CAPM／APT、股票與固定收益、衍生工具、效率市場、主動管理與績效評估。
- 資產配置與分散化採金融監理／投資教育機構的標準定義：分散化降低集中風險但不保證避免損失。
- 臺灣交易制度若需舉例，以臺灣證券交易所等官方最新資料為優先，不把會快速變動的制度數字寫成核心必背內容。
