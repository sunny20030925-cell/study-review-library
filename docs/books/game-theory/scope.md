# 《賽局理論及應用》科目範圍

## 定位

- Book ID：`game-theory`
- 書名：《賽局理論及應用》
- 副標：策略互動・Nash 均衡・動態賽局・資訊不完全與制度設計
- 層級：一般大學部賽局理論／Game Theory and Applications，共同核心從接近零基礎銜接一般大學課程與考試。
- 讀者起點：不要求先修高等個體經濟學；只預設基本代數、函數與簡單機率。必要的期望值、條件機率與折現會在正文就地補足。

本書主線是「先辨認誰與誰互相影響 → 把情境寫成策略式或展開式賽局 → 選對解概念 → 求均衡 → 檢查可信性與資訊條件 → 再解讀應用」。案例可取自廠商競爭、談判、拍賣、公共財、網路與日常策略互動，但案例只服務賽局概念，不把本書改寫成個體經濟學、產業經濟學、財務學或作業研究專題。

## 核心範圍

1. 賽局理論的分析地圖：玩家、行動、策略、資訊、報酬、時序與解概念。
2. 策略式賽局（normal-form game）、最佳回應（best response）與報酬矩陣。
3. 嚴格／弱優勢、嚴格劣勢策略的反覆刪除與合理化（rationalizability）直覺。
4. 純策略 Nash 均衡：互為最佳回應、均衡存在與多重均衡的基本判讀。
5. 混合策略 Nash 均衡：機率策略、無差異條件、支撐集與 2×2 標準解法。
6. 零和賽局：maximin、minimax、鞍點、混合策略與 minimax theorem 的入門意義。
7. 連續策略賽局與反應函數：以 Cournot、Bertrand、公共財等標準模型練習最佳回應與聯立均衡。
8. 展開式賽局（extensive-form game）：賽局樹、資訊集合、純／行為策略與向後歸納。
9. 子賽局完美 Nash 均衡（SPNE）：子賽局、可信威脅、承諾與先後行動優勢。
10. 議價：最後通牒、交替出價、折現與 Nash bargaining solution 的基本比較。
11. 重複賽局：有限／無限重複、觸發策略、折現因子、合作可持續條件與 folk theorem 直覺。
12. 不完全資訊與 Bayesian game：型態、共同先驗、策略作為型態到行動的映射、Bayesian Nash equilibrium（BNE）。
13. 拍賣：第一價、第二價、私人價值、共同價值／贏家詛咒直覺、收益等價的適用條件。
14. 動態不完全資訊賽局與 Perfect Bayesian Equilibrium（PBE）：信念、序列理性與 Bayes 更新。
15. 訊號賽局：分離、混同、半分離直覺；教育、品質、融資等標準應用。
16. 篩選與 cheap talk：自我選擇、誘因相容、資訊揭露與無成本訊息何時具有資訊。
17. 機制設計入門：社會選擇、直接機制、揭示原理、誘因相容、個別理性、VCG 直覺。
18. 合作賽局入門：聯盟、可轉移效用、core、Shapley value，以及與非合作均衡的差別。
19. 應用與整合：寡占、進入阻擋、公共財／共有資源、擁擠與網路、協調／反協調；建立模型、選解概念、檢查假設與解讀比較靜態。
20. 綜合解題與模型判讀：從文字題轉成賽局、判斷資訊與時序、挑選 NE／SPNE／BNE／PBE、辨認均衡精煉與常見陷阱。

## 深度邊界

正文與核心題庫不擴張至：

- 博士班層級的 epistemic game theory、完整 belief hierarchy、global games 或高階均衡精煉證明。
- Kakutani／Brouwer fixed-point theorem 的嚴格拓撲證明；只保留均衡存在所需的直覺與條件。
- 測度論型連續型態空間、隨機賽局、微分賽局、平均報酬 stochastic games。
- 演算法賽局理論、PPAD 複雜度、線上學習 regret bounds 的完整證明。
- 高階拍賣設計、Myerson optimal auction、完整 matching theory 或市場設計專題。
- 高階機制設計的 implementation theory、Gibbard–Satterthwaite 等完整證明體系。
- 產業組織、財務、政治學、網路科學等應用領域的專門模型細節。

上述內容若有助於理解，只能以「選讀／延伸」或邊界說明出現，不占核心題庫與必讀進度。

## 重要精確性規則

- 「Nash 均衡」只代表在其他玩家策略固定時，任何單一玩家都沒有單方面偏離的誘因；不得寫成必然有效率、公平、唯一或社會最佳。
- 優勢策略均衡比 Nash 均衡更強；有 Nash 均衡不代表存在優勢策略。
- 反覆刪除嚴格劣勢策略與刪除弱劣勢策略要區分；弱劣勢的刪除順序可能影響結果。
- 混合策略均衡中，玩家在其正機率支撐集內的純策略必須給相同最高期望報酬；不能把「自己隨機化」當成直接讓自己無差異的因果理由。
- 零和賽局的 minimax 結論不得直接套到一般總和賽局。
- SPNE 必須在每一個真正的子賽局中都誘導 Nash 均衡；不是只做一次向後歸納就自動成立。
- 有限次重複且具有唯一階段賽局 Nash 的標準完全資訊模型，向後歸納通常排除以未來懲罰維持最後期合作；無限重複的合作條件需明示折現與策略假設。
- Bayesian game 的策略是「型態 → 行動」的完整應變計畫；BNE 的期望報酬必須依玩家在決策時可用的資訊計算。
- PBE 至少包含完整策略與信念，並要求序列理性；到達機率為正的資訊集合依 Bayes rule 更新。零機率路徑外信念不可任意拿來合理化不可信行為而不加說明。
- 第一價與第二價拍賣的策略結論需先說明私人價值／獨立性／風險中立等假設；第二價拍賣「誠實出價」是特定標準私人價值模型下的弱優勢結果。
- Nash bargaining solution 與交替出價的 Rubinstein bargaining equilibrium 是不同概念，不得混稱。
- cooperative game 的 core、Shapley value 與 non-cooperative Nash equilibrium 解的是不同問題，不能互相替代。
- 機制設計的 incentive compatibility、individual rationality 與 efficiency 必須分開檢查；VCG 的良好性質有明確偏好與準線性等條件。

## 成品結構

- 正文：第 0 章至第 19 章，共 20 章。
- 附錄：核心符號／解概念速查、標準解題路線、中英名詞對照，共 3 份。
- 題庫：100 題，每章 5 題，涵蓋基礎理解、標準計算／均衡判讀、綜合推理與常見陷阱。
- 搜尋索引：至少 150 筆。
- 圖解：20 張自製 SVG，每章至少一張真正幫助理解的報酬矩陣、反應圖、賽局樹、資訊集合、信念／機制流程或聯盟結構圖。
- 平板功能：沿用共同 PWA 的連續閱讀、章節導覽、全文搜尋、題庫練習、閱讀進度、錯題紀錄與離線快取。
