## 部署流程

1. GitHub Actions 下載固定 ID 的正式網站部署包。
2. 先核對部署包 SHA-256，再用 Python ZIP 模組解開；部署包可含前置檔頭，不依賴桌面解壓工具。
3. 執行 repo 內的會計學第二版修正腳本，重建搜尋索引並驗證 14 章、70 題與指定修正內容。
4. 驗證三本書的 manifest、題庫數量、章節檔、搜尋索引、圖解與 PWA 快取。
5. JavaScript 語法與全部正式檢查通過後，才上傳 Pages artifact。
6. Pages 部署成功後寫回 `docs/deployment_receipt.json`，失敗時不會產生成功回條。
7. 使用者不需要在平板上處理 ZIP、Git 或部署。
